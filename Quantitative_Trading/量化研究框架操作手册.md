# 沪深300量化研究框架操作手册

## 1. 研究范围

本框架使用现有SQLite中的历史沪深300定期调整股票池、原始日行情和前复权日行情，研究不依赖历史指数权重的月度选股策略。首版支持历史成分等权、横截面动量、低波动和动量低波动复合策略。

该框架用于研究和模拟，不构成收益保证，也不应在未经样本外验证和模拟盘检验时直接连接实盘账户。

## 2. 架构

```text
SQLite历史数据库
       │
       ├── 公司行为账本：巨潮资讯明细 + 本地复权因子对账
       ├── pandas：完整历史上计算因子
       ├── 历史股票池：按信号日过滤成分股
       ├── 月末信号：收盘后生成目标组合
       └── Backtrader：下一交易日开盘执行、账户和订单核算
                    │
                    └── CSV、JSON和净值图
```

信号使用前复权价格，模拟成交使用不复权开盘价，Backtrader账户按不复权收盘价估值。信号日在月末收盘后产生，订单最早在下一交易日开盘执行；目标金额以现金和各持仓当日开盘价计算，不读取当日收盘价，避免使用未来数据。

公司行为账本以巨潮资讯实施公告为事件明细主源，以Baostock原始价格和前复权价格反推的复权因子作为独立核验。普通现金分红按税前金额增加现金，送股和转增按公告比例增加持股；无法由普通分红公告解释的配股、重整或代码变更等事件使用本地复权比例作为合成股数乘数。合成乘数用于保持研究净值连续，不等同于交易所实际交收股数。

## 3. 安装

运行环境为Python 3.12。正式SQLite必须已经位于：

```text
data_v5/csi300_2020_present.sqlite
```

在项目根目录安装依赖：

```powershell
python -m pip install -r requirements-research.txt
```

正式运行策略前，必须确认公司行为账本已经存在。首次联网构建：

```powershell
python build_corporate_actions.py
python build_security_status.py
python validate_csi300_sqlite.py
```

脚本按证券保存完成状态，重复执行时自动跳过已成功证券。归档位于 `data_v5/corporate_actions/`，其中 `manifest.json`记录4个CSV的行数和SHA-256。数据库重建后可验签并完全离线恢复：

```powershell
python build_corporate_actions.py --import-dir data_v5/corporate_actions
python build_security_status.py --import-dir data_v5/security_status
python validate_csi300_sqlite.py
```

校验报告必须满足 `errors=[]`。如果公司行为表缺失或请求区间存在 `mismatch` 级事件，`run_research.py`会直接停止，不会静默退回到未处理公司行为的估值方式。

公司行为和ST状态在回测时只从SQLite读取。`data_v5/security_status/manifest.json`保存760,363行状态归档的SHA-256。若要求完全离线，还必须确保 `data_v5/benchmarks/csi300_daily.csv` 已存在并覆盖请求区间；否则研究入口会联网下载沪深300基准。

## 4. 运行首个策略

运行研究前先维护数据库：

```powershell
python update_csi300_incremental.py --full-validate
```

若输出包含`success_pending_official`，表示行情已经更新，但存在尚未由官方Excel确认的成分变化。此时研究仍使用冻结的正式股票池，报告必须继续披露临时调整省略和待确认状态。

动量与低波动复合策略：

```powershell
python run_research.py --strategy momentum_low_vol --start-date 2021-01-04 --end-date 2026-08-05 --top-n 30
```

历史成分等权基准：

```powershell
python run_research.py --strategy equal_weight --start-date 2021-01-04 --end-date 2026-08-05 --initial-cash 100000000
```

单因子策略：

```powershell
python run_research.py --strategy momentum --start-date 2021-01-04 --end-date 2026-08-05 --top-n 30
python run_research.py --strategy low_vol --start-date 2021-01-04 --end-date 2026-08-05 --top-n 30
```

CLI默认日期为2021-01-04至2026-08-05，默认本金为10,000,000元，默认数据库为上述正式SQLite，默认输出目录为 `research_outputs/<策略>_<开始日期>_<结束日期>/`。为了让不同策略可以比较，建议显式传入相同的起止日期和本金。

## 5. 默认因子

| 因子 | 默认定义 |
|---|---|
| 动量 | 过去252交易日至21交易日前的前复权收益 |
| 波动率 | 最近60个交易日收益率标准差年化 |
| 流动性 | 最近20个交易日平均成交额 |
| 复合分数 | 动量百分位与低波动百分位各占50% |
| 股票池 | 信号日的历史沪深300定期调整成分，并排除当日ST股票 |
| 调仓 | 每月最后一个交易日生成信号，下一交易日开盘执行 |

策略差异如下：

| 策略 | 流动性过滤 | 选择数量 | 分数 | 目标总仓位 |
|---|---|---:|---|---:|
| `equal_weight` | 不做分位过滤，但要求20日平均成交额存在 | 当日全部可用成分，通常接近300只 | 固定相同 | 95% |
| `momentum` | 排除20日平均成交额后20% | 默认30只 | 动量百分位 | 95% |
| `low_vol` | 排除20日平均成交额后20% | 默认30只 | 低波动百分位 | 95% |
| `momentum_low_vol` | 排除20日平均成交额后20% | 默认30只 | 动量和低波动各50% | 95% |

动量默认比较252个交易日前与21个交易日前的价格，至少需要约253个有效交易日观测；“跳过21日”包含在252日窗口内，不与252相加。程序会自动从 `start_date` 之前读取最多262个交易日用于预热；历史仍不足或因子为空的股票在该期被跳过，不会使用未来数据。若整期没有合格股票，则该期不生成调仓目标。

## 6. 交易假设

| 项目 | 默认值或规则 |
|---|---|
| 初始资金 | 10,000,000元；300股等权示例使用100,000,000元 |
| 买卖佣金 | 成交额0.03%，最低5元 |
| 卖出印花税 | 2023-08-28前0.1%，当日起0.05% |
| 过户费 | 2022-04-29前双向0.002%，当日起双向0.001% |
| 滑点 | 单边0.1% |
| 交易单位 | 100股整数手 |
| 停牌 | 不成交 |
| 未成交重试 | 最多5个交易日 |
| ST股票涨跌停 | 依据Baostock历史`isST`字段约5% |
| 非ST主板涨跌停 | 约10% |
| 科创板及改革后创业板 | 约20% |
| 现金分红 | 除权日按税前每股现金增加账户现金 |
| 送股、转增 | 除权日按公告比例增加持股数量 |
| 特殊复权事件 | 按本地前复权比例调整合成持股数量 |

印花税和过户费按成交日期自动切换，过户费在买卖双向收取。使用 `--flat-fee-schedule` 可关闭历史切换，并让全区间采用 `--sell-stamp-duty` 和 `--transfer-fee`，适合保守压力测试。滑点由Backtrader在买入价上调、卖出价下调，并受当日OHLC范围限制。目标股数按开盘价向下取整到100股整数手，95%总仓位用于预留现金、费用和滑点。最低5元佣金按每笔成交订单收取。

除权日的处理顺序固定为：开盘订单之前应用公司行为，随后用“可用现金 + 各持仓当日开盘市值”计算组合资产和目标股数，再执行当日订单，最后按不复权收盘价估值。税前现金分红在该次开盘目标计算中视为可用现金；这是日线研究近似，不代表券商真实派息到账时间。

100股整数手约束只用于普通月度目标买入和目标仓位计算。公告送转和`factor_only`合成乘数可产生非100整数倍甚至小数持股；这些尾差继续按不复权价格估值，在后续调仓时随目标差额整体卖出并按实际名义金额计费。`orders.csv`可能因此出现小数卖出数量，必须结合`corporate_actions.csv`中的`factor_fallback`解释，不能当作交易所可直接申报的订单。

5日重试包含首次执行日及之后最多4个交易日。首次调仓时按当日开盘价和组合资产确定整数股目标，后续重试沿用该股数，不随价格重新计算。Backtrader日线模型只支持整笔成交或整笔跳过，不模拟部分成交；新的月度信号会替换旧目标，回测结束时未完成目标自然终止。

月度策略不会在买入当天卖出，因此自然满足当前策略范围内的T+1约束。涨跌停判断没有历史ST标签、IPO无涨跌幅阶段及精确价格笼子数据，只能视为保守近似。

## 7. 输出文件

默认输出目录示例：

```text
research_outputs/momentum_low_vol_2021-01-04_2026-08-05/
├── signals.csv
├── orders.csv
├── skipped_orders.csv
├── corporate_actions.csv
├── equity_curve.csv
├── equity_curve.png
└── summary.json
```

`signals.csv`每行是一个目标股票；`orders.csv`每行是一次最终成交、拒单或取消状态；`skipped_orders.csv`按日期逐条记录每次未提交的尝试，因此同一目标在重试期间可能出现多行；`corporate_actions.csv`记录实际持仓上发生的现金、股数、处理方法和核验状态。5日到期或回测截止后不会伪造成交。`summary.json`保存策略与沪深300基准指标、完整参数、公司行为处理数量和仍需披露的警告。

如果目标金额不足以买入100股，`skipped_orders.csv`会记录 `below_lot`。资金较小时，“300只成分股等权”会变成大量现金和少数低价股票，不能解释为理论等权指数；应提高模拟本金或明确研究的是实际小资金可执行组合。1亿元等权示例只投资95%，每只股票的目标金额按9,500万元除以当期可用股票数计算。

默认沪深300基准通过Baostock `sh.000300` 不复权指数日线获得。它是价格指数，不含成分股现金分红，而策略账本含税前分红，因此默认相对收益不是严格同口径的总回报比较。首次运行或日期覆盖不足时自动下载并保存到：

```text
data_v5/benchmarks/csi300_daily.csv
```

后续运行优先复用本地文件。基准下载需要网络，来源与路径会写入 `summary.json`。

如取得官方沪深300全收益指数 `H00300`，准备至少包含 `date,close` 两列的CSV后运行：

```powershell
python run_research.py --benchmark data_v5/benchmarks/csi300_total_return.csv --benchmark-return-type total_return --benchmark-source csindex_H00300 --strategy momentum_low_vol
```

`total_return`模式禁止自动下载价格指数；文件不存在、字段错误或日期覆盖不足时会直接报错。当前免费接口未能稳定取得 `H00300`，因此现有样例仍使用价格指数并在 `summary.json` 中明确警告。

## 9. 当前限制

- 数据库实际日期范围为2020-01-02至2026-08-05；
- 股票池只覆盖半年定期调整，临时调整日期未纳入；
- 已知133个成员日没有行情，涉及`600837`和`601989`；因子缺失时不入选，执行日无价格条时记录跳过；
- 不使用历史沪深300指数权重；
- 默认基准是沪深300价格指数，不含分红；缺少可靠的官方`H00300`全收益历史文件；
- 没有历史行业、ST状态和财务数据；
- 现金分红按税前金额计算，未模拟个人投资者按持有期限结算的差别化红利税；
- 分红应收款和送转股份在除权日确认，未单独模拟派息日、到账日及期间不可用资金或不可卖股份；
- 3,384个复权变化事件中，17个只能使用复权因子合成股数兜底；合成股数可能产生小数，相关卖单不是交易所真实股数；
- 54个公告账本收益与Baostock前复权收益的单日差异介于0.2%和1%，已标记为`review`，没有`mismatch`阻断事件；
- 历史ST状态已覆盖全部行情行，但IPO前五日无涨跌幅阶段、复牌特殊规则和精确价格笼子仍未建模；
- Baostock是当前唯一行情源；
- 复权历史可能被供应商重算。

正式评价策略时，应至少比较沪深300指数、历史成分等权策略和目标策略，并检查不同起止日期、参数、手续费和滑点下结果是否稳定。进入模拟盘前仍需补齐差别化红利税、精确涨跌停/ST规则和临时成分调整；公司行为“完全未记账”已不再是当前阻断项。
