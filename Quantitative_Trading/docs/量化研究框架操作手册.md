# 沪深300量化研究框架操作手册

## 1. 研究范围

本框架使用现有SQLite中的历史沪深300定期调整股票池、原始日行情和前复权日行情，研究不依赖历史指数权重的月度选股策略。首版支持历史成分等权、横截面动量、低波动和动量低波动复合策略。

该框架用于研究和模拟，不构成收益保证，也不应在未经样本外验证和模拟盘检验时直接连接实盘账户。

## 2. 架构

```text
SQLite历史数据库
       │
       ├── 公司行为账本：巨潮资讯明细 + 本地复权因子对账
       ├── pandas：完整历史上计算因子
       ├── 历史股票池：按信号日过滤成分股
       ├── 月末信号：收盘后生成目标组合
       └── Backtrader：下一交易日开盘执行、账户和订单核算
                    │
                    └── CSV、JSON和净值图
```

信号使用前复权价格，模拟成交使用不复权开盘价，Backtrader账户按不复权收盘价估值。信号日在月末收盘后产生，订单最早在下一交易日开盘执行；目标金额以现金和各持仓当日开盘价计算，不读取当日收盘价，避免使用未来数据。

公司行为账本以巨潮资讯实施公告为事件明细主源，以Baostock原始价格和前复权价格反推的复权因子作为独立核验。普通现金分红按税前金额增加现金，送股和转增按公告比例增加持股；无法由普通分红公告解释的配股、重整等事件使用本地复权比例作为合成股数乘数。跨证券代码吸收合并不再使用复权因子替代，而是由 `security_transitions` 表按官方换股比例和新增股份上市日转移持仓。

## 3. 安装

运行环境为Python 3.12。正式SQLite必须已经位于：

```text
data/csi300_2010_present.sqlite
```

在项目根目录安装依赖：

```powershell
python -m pip install -r requirements-research.txt
```

正式运行策略前，必须确认公司行为账本已经存在。首次联网构建：

```powershell
python build_corporate_actions.py
python build_security_status.py
python build_security_transitions.py
python scripts/validate/validate_csi300_sqlite.py
```

脚本按证券保存完成状态，重复执行时自动跳过已成功证券。归档位于 `data/corporate_actions/`，其中 `manifest.json`记录4个CSV的行数和SHA-256。数据库重建后可验签并完全离线恢复：

```powershell
python build_corporate_actions.py --import-dir data/corporate_actions
python build_security_status.py --import-dir data/security_status
python build_security_transitions.py
python scripts/validate/validate_csi300_sqlite.py
```

校验报告必须满足 `errors=[]`。如果公司行为表缺失或请求区间存在 `mismatch` 级事件，`scripts/research/run_research.py`会直接停止，不会静默退回到未处理公司行为的估值方式。

公司行为、ST状态和跨代码结算事件在回测时只从SQLite读取。`data/security_status/manifest.json`保存状态归档的SHA-256；`data/security_transitions/manifest.json`保存官方核验事件CSV的行数和SHA-256。若要求完全离线，还必须确保 `data/benchmarks/csi300_daily.csv` 已存在并覆盖请求区间；否则研究入口会联网下载沪深300基准。

## 4. 运行首个策略

运行研究前先维护数据库：

```powershell
python scripts/build/update_csi300_incremental.py --full-validate
```

若输出包含`success_pending_official`，表示行情已经更新，但存在尚未由官方Excel确认的成分变化。此时研究仍使用冻结的正式股票池，报告必须继续披露临时调整省略和待确认状态。

当前主研究候选（双月调仓、50只、10只排名缓冲）：

```powershell
python scripts/research/run_research.py --strategy momentum_low_vol --start-date 2021-01-04 --top-n 50 --rebalance-interval-months 2 --selection-buffer 10
```

默认月频复合策略对照：

```powershell
python scripts/research/run_research.py --strategy momentum_low_vol --start-date 2021-01-04 --top-n 30
```

显式修改因子窗口时使用：

```powershell
python scripts/research/run_research.py --strategy momentum_low_vol --momentum-lookback 126 --momentum-skip 10 --volatility-lookback 40 --liquidity-lookback 20 --top-n 30
```

历史成分等权基准：

```powershell
python scripts/research/run_research.py --strategy equal_weight --start-date 2021-01-04 --initial-cash 100000000
```

单因子策略：

```powershell
python scripts/research/run_research.py --strategy momentum --start-date 2021-01-04 --top-n 30
python scripts/research/run_research.py --strategy low_vol --start-date 2021-01-04 --top-n 30
```

CLI默认开始日为2021-01-04；省略 `--end-date` 时自动使用SQLite交易日历中的最后一个交易日，因此每日增量更新后无需修改研究命令。默认本金为10,000,000元，默认数据库为上述正式SQLite，默认输出目录为 `research_outputs/<策略>_<开始日期>_<实际结束日期>/`。为了让不同策略可以比较，必须使用相同的数据库快照、起止日期和本金；需要冻结实验时应显式传入 `--end-date`。

## 5. 默认因子

| 因子 | 默认定义 |
|---|---|
| 动量 | 过去252交易日至21交易日前的前复权收益 |
| 波动率 | 最近60个交易日收益率标准差年化 |
| 流动性 | 最近20个交易日平均成交额 |
| 复合分数 | 动量百分位与低波动百分位各占50% |
| 股票池 | 信号日的历史沪深300定期调整成分，并排除当日ST股票 |
| 调仓 | 默认每月最后一个交易日生成信号，下一交易日开盘执行 |

策略差异如下：

| 策略 | 流动性过滤 | 选择数量 | 分数 | 目标总仓位 |
|---|---|---:|---|---:|
| `equal_weight` | 不做分位过滤，但要求20日平均成交额存在 | 当日全部可用成分，通常接近300只 | 固定相同 | 95% |
| `momentum` | 排除20日平均成交额后20% | 默认30只 | 动量百分位 | 95% |
| `low_vol` | 排除20日平均成交额后20% | 默认30只 | 低波动百分位 | 95% |
| `momentum_low_vol` | 排除20日平均成交额后20% | 默认30只 | 动量和低波动各50% | 95% |

动量默认比较252个交易日前与21个交易日前的价格，至少需要约253个有效交易日观测；“跳过21日”包含在252日窗口内，不与252相加。程序会自动从 `start_date` 之前读取最多262个交易日用于预热；历史仍不足或因子为空的股票在该期被跳过，不会使用未来数据。若整期没有合格股票，则该期不生成调仓目标。

`--rebalance-interval-months`控制调仓间隔，允许1至12的整数。周期使用固定日历锚点，不随回测开始日漂移：双月策略在2、4、6、8、10、12月末生成信号，季度策略在3、6、9、12月末生成信号。`--selection-buffer N`只对因子选股策略生效：上期持仓只要本期排名仍在前 `top_n + N` 内就保留，再按本期排名补足至 `top_n`；跌出股票池、ST、停牌、因子或流动性不合格的旧持仓不会因缓冲而保留。缓冲值为0时等价于每期严格选择前 `top_n`，历史成分等权策略忽略该参数。

## 6. 交易假设

| 项目 | 默认值或规则 |
|---|---|
| 初始资金 | 10,000,000元；300股等权示例使用100,000,000元 |
| 买卖佣金 | 成交额0.03%，最低5元 |
| 卖出印花税 | 2023-08-28前0.1%，当日起0.05% |
| 过户费 | 2022-04-29前双向0.002%，当日起双向0.001% |
| 滑点 | 单边0.1% |
| 交易单位 | 100股整数手 |
| 停牌 | 不成交 |
| 未成交重试 | 最多5个交易日 |
| ST股票涨跌停 | 依据Baostock历史`isST`字段约5% |
| 非ST主板涨跌停 | 约10% |
| 科创板及改革后创业板 | 约20% |
| 现金分红 | 除权日按税前每股现金增加账户现金 |
| 送股、转增 | 除权日按公告比例增加持股数量 |
| 特殊复权事件 | 按本地前复权比例调整合成持股数量 |
| 吸收合并换股 | 新增目标股份上市日按官方比例从源代码转至目标代码，不收交易费用 |

印花税和过户费按成交日期自动切换，过户费在买卖双向收取。使用 `--flat-fee-schedule` 可关闭历史切换，并让全区间采用 `--sell-stamp-duty` 和 `--transfer-fee`，适合保守压力测试。滑点由Backtrader在买入价上调、卖出价下调，并受当日OHLC范围限制。目标股数按开盘价向下取整到100股整数手，95%总仓位用于预留现金、费用和滑点。最低5元佣金按每笔成交订单收取。

除权日的处理顺序固定为：开盘订单之前应用公司行为，随后用“可用现金 + 各持仓当日开盘市值”计算组合资产和目标股数，再执行当日订单，最后按不复权收盘价估值。税前现金分红在该次开盘目标计算中视为可用现金；这是日线研究近似，不代表券商真实派息到账时间。

当前已核验两笔跨代码事件：`600837`海通证券按`1:0.62`于2025-03-17转为`601211`国泰海通；`601989`中国重工按`1:0.1339`于2025-09-16转为`600150`中国船舶。公告规定不足一股由登记结算系统按尾数排序、同尾数时随机分配，单一回测账户无法复刻登记系统的全体股东排序，因此程序采用就近整数近似，误差不超过一股并写入 `security_transitions.csv`。证券行情永久结束、持仓仍大于零且没有已核验结算事件时，正式回测直接报错。

100股整数手约束只用于普通调仓目标买入和目标仓位计算。公告送转和`factor_only`合成乘数可产生非100整数倍甚至小数持股；这些尾差继续按不复权价格估值，在后续调仓时随目标差额整体卖出并按实际名义金额计费。`orders.csv`可能因此出现小数卖出数量，必须结合`corporate_actions.csv`中的`factor_fallback`解释，不能当作交易所可直接申报的订单。

5日重试包含首次执行日及之后最多4个交易日。首次调仓时按当日开盘价和组合资产确定整数股目标，后续重试沿用该股数，不随价格重新计算。Backtrader日线模型只支持整笔成交或整笔跳过，不模拟部分成交；新的调仓信号会替换旧目标，回测结束时未完成目标自然终止。

当前低频策略不会在买入当天卖出，因此自然满足当前策略范围内的T+1约束。涨跌停判断没有IPO无涨跌幅阶段及精确价格笼子数据，只能视为保守近似。

## 7. 输出文件

默认输出目录示例：

```text
research_outputs/momentum_low_vol_2021-01-04_2026-08-10/
├── signals.csv
├── orders.csv
├── skipped_orders.csv
├── corporate_actions.csv
├── security_transitions.csv
├── equity_curve.csv
├── equity_curve.png
└── summary.json
```

`signals.csv`每行是一个目标股票；`orders.csv`每行是一次最终成交、拒单或取消状态，并记录开盘基准价、成交名义金额、滑点损耗和全日成交额参与率；`skipped_orders.csv`记录每次未提交的尝试；`corporate_actions.csv`记录实际持仓发生的现金和股数事件；`security_transitions.csv`记录实际持仓发生的跨代码换股。`summary.json`还包含显式费用、滑点、换手率和容量近似指标。

如果目标金额不足以买入100股，`skipped_orders.csv`会记录 `below_lot`。资金较小时，“300只成分股等权”会变成大量现金和少数低价股票，不能解释为理论等权指数；应提高模拟本金或明确研究的是实际小资金可执行组合。1亿元等权示例只投资95%，每只股票的目标金额按9,500万元除以当期可用股票数计算。

默认沪深300基准通过Baostock `sh.000300` 不复权指数日线获得。它是价格指数，不含成分股现金分红，而策略账本含税前分红，因此默认相对收益不是严格同口径的总回报比较。首次运行或日期覆盖不足时自动下载并保存到：

```text
data/benchmarks/csi300_daily.csv
```

后续运行优先复用本地文件。基准下载需要网络，来源与路径会写入 `summary.json`。

如取得官方沪深300全收益指数 `H00300`，准备至少包含 `date,close` 两列的CSV后运行：

```powershell
python scripts/research/run_research.py --benchmark data/benchmarks/csi300_total_return.csv --benchmark-return-type total_return --benchmark-source csindex_H00300 --strategy momentum_low_vol
```

`total_return`模式禁止自动下载价格指数；文件不存在、字段错误或日期覆盖不足时会直接报错。当前免费接口未能稳定取得 `H00300`，因此现有样例仍使用价格指数并在 `summary.json` 中明确警告。

## 8. 策略验收

正式策略不能只看一次全样本净值。运行以下命令比较7组月频、双月和季度候选，执行因子IC和五分组收益、前两年选择参数后下一年执行的滚动检验，并对每个候选分别运行含费与零费用完整撮合：

```powershell
python run_research_validation.py
```

输出位于 `research_outputs/validation_low_turnover/`。`candidate_formal_backtests.csv`保存每个候选的含费/零费全期指标、2023年以后指标、成本、换手和综合排序；`candidate_yearly_metrics.csv`保存逐年表现；`candidate_daily_returns.csv`和`candidate_signals.csv`用于复核；其余核心文件包括 `parameter_sensitivity.csv`、`factor_ic.csv`、`factor_quantile_returns.csv`、`walk_forward.csv`、`walk_forward_daily_returns.csv`和`summary.json`。参数粗筛收益按实际调仓间隔年化，不再把双月或季度收益误当成每年12期。滚动训练只使用执行日至下一执行日的前复权收盘收益排序，测试年度使用完整Backtrader执行模型，不把该测试年度收益反馈给当年参数选择。

截至2026-08-10的含成本验收显示：动量IC均值0.0199、t值0.64，低波IC均值0.0921、t值2.64，低波信号明显更可靠。默认月频30只复合策略全期收益9.82%、最大回撤-33.69%、年化总换手8.67倍；双月50只、缓冲10只的复合候选收益29.10%、最大回撤-21.07%、年化总换手3.94倍，显式费用与滑点合计约35.97万元，成本拖累约4.53个百分点。纯低波月频30只收益46.71%、2023年以来Sharpe约1.03，但年化换手仍为7.24倍；纯低波季度50只、缓冲20只的年化换手最低为2.42倍，收益26.40%。

当前主研究候选为 `momentum_low_vol / top_n=50 / rebalance_interval_months=2 / selection_buffer=10`，原因是其回撤、成本、换手和年度正收益比例较均衡；纯低波月频30只作为收益型对照，纯低波季度50只、缓冲20只作为低成本对照。滚动规则在2023和2024年选择纯低波月频，在2025和2026年选择快速双月复合，2023年至2026-08-10拼接收益为62.70%、最大回撤-10.47%；但候选集合和规则是在观察现有历史后建立，该拼接结果仍有研究者自由度和选择偏差，不能视为真正未见数据，也不能作为实盘收益预期。

主候选完整报告位于 `research_outputs/candidate_balanced_bimonthly_50_buffer10/`。下一阶段应冻结候选和参数，进行至少6至12个月不回改规则的模拟盘/前向观察，同时补做牛熊分段、风格暴露和更严格滑点压力测试；在此之前状态仍为研究候选，不是实盘批准。

## 10. 当前限制

- 数据库实际日期范围为2020-01-02至2026-08-10；
- 股票池只覆盖半年定期调整，临时调整日期未纳入；
- 已知成员日缺价集中在吸收合并停牌至定期调出期间，涉及`600837`和`601989`；已持仓按官方事件结算，其他没有结算事件的永久缺价持仓会阻断回测；
- 不使用历史沪深300指数权重；
- 默认基准是沪深300价格指数，不含分红；缺少可靠的官方`H00300`全收益历史文件；
- 没有历史行业和财务数据；历史ST状态已经覆盖全部行情行；
- 现金分红按税前金额计算，未模拟个人投资者按持有期限结算的差别化红利税；
- 分红应收款和送转股份在除权日确认，未单独模拟派息日、到账日及期间不可用资金或不可卖股份；
- 3,393个复权变化事件中，17个只能使用复权因子合成股数兜底；合成股数可能产生小数，相关卖单不是交易所真实股数；
- 54个公告账本收益与Baostock前复权收益的单日差异介于0.2%和1%，已标记为`review`，没有`mismatch`阻断事件；
- 历史ST状态已覆盖全部行情行，但IPO前五日无涨跌幅阶段、复牌特殊规则和精确价格笼子仍未建模；
- Baostock是当前唯一行情源；
- 复权历史可能被供应商重算。

正式评价策略时，应至少比较沪深300指数、历史成分等权策略和目标策略，并检查不同起止日期、参数、手续费和滑点下结果是否稳定。进入模拟盘前仍需补齐差别化红利税、精确涨跌停/ST规则和临时成分调整；公司行为“完全未记账”已不再是当前阻断项。
