# 沪深300成分股日线数据 — 字段说明文档

> **数据范围**: 2020-01-02 至 2026-08-06
>
> **股票数量**: 300只（沪深300成分股）
>
> **复权方式**: 前复权（按分红送股调整历史价格）
>
> **数据来源**: Baostock (http://baostock.com)
>
> **获取时间**: 2026-08-06

---

## 一、文件结构

每只股票对应一个CSV文件，文件名为 `{股票代码}_{股票名称}.csv`，例如：

```
000001_平潭发展.csv
600519_贵州茅台.csv
300750_宁德时代.csv
688981_中芯国际.csv
```

每个文件包含 **9列**，字段顺序固定为：

| 列名 | 数据类型 | 说明 |
|------|----------|------|
| `date` | object (字符串) | 交易日期，格式 YYYY-MM-DD |
| `open` | float64 | 开盘价（前复权） |
| `high` | float64 | 最高价（前复权） |
| `low` | float64 | 最低价（前复权） |
| `close` | float64 | 收盘价（前复权） |
| `volume` | int64 | 成交量（股） |
| `amount` | float64 | 成交额（元） |
| `code` | int64 | 股票代码 |
| `name` | object (字符串) | 股票名称 |

## 二、逐字段详解

### 2.1 `date` — 交易日期

- **格式**: `YYYY-MM-DD`，如 `2020-01-02`
- **含义**: 该条记录对应的交易日
- **注意**:
  - 仅包含交易日（不含周末和法定节假日）
  - 停牌期间无记录，日期会出现跳跃
  - 最大日期间隔通常为3天（周末跳过），但节假日可能导致更长间隔

**示例**:
```
2020-01-02   ← 正常交易日
2020-01-03   ← 次日交易日
2020-01-06   ← 跳过周末（1/4、1/5为周六日）
2020-01-07
2020-01-08
2020-01-09
2020-01-10
2020-01-13   ← 跳过周末（1/11、1/12为周六日）
2020-01-14
2020-01-15
2020-01-16
2020-01-17
2020-02-03   ← 春节长假（1/24-2/2休市），间隔11天
```

### 2.2 `open` — 开盘价（前复权）

- **含义**: 当日第一笔成交的价格
- **单位**: 人民币元/股
- **复权说明**: 经过前复权调整，已根据历史分红送股进行回溯修正
- **特点**:
  - 前复权后，历史价格可能低于实际交易时的价格
  - 复权后价格序列在分红除权日会出现价格"跳空"，但K线连续
  - 数值精度约6位小数

**示例** (贵州茅台 600519):
```
date       open          含义
2020-01-02 954.720024   当日开盘价，前复权后
2020-01-03 945.409811   当日开盘价
2020-01-06 906.357699   当日开盘价
```

### 2.3 `high` — 最高价（前复权）

- **含义**: 当日成交的最高价格
- **单位**: 人民币元/股
- **与前复权的关系**: 同 `open`，经过分红送股调整

**示例**:
```
date       open       high      当日振幅
2020-01-02 954.720024  969.159318  high - open = 14.44 (涨幅1.51%)
```

### 2.4 `low` — 最低价（前复权）

- **含义**: 当日成交的最低价格
- **单位**: 人民币元/股
- **与前复权的关系**: 同 `open`

**示例**:
```
date       open       high       low        close    当日振幅
2020-01-02 954.720024  969.159318  944.563428  956.41279  24.60 (2.58%)
```
上例中，当日振幅 = high - low = 24.60元

### 2.5 `close` — 收盘价（前复权）

- **含义**: 当日最后一笔成交的价格
- **单位**: 人民币元/股
- **重要性**: 收盘价是技术分析最常用的价格，也是计算涨跌幅、收益率的基础
- **前复权影响**: 连续K线在分红除权日会出现价格向下跳空，但后续价格会与跳空前连续

**示例**:
```
date       close    次日涨跌
2020-01-02 956.412790  —
2020-01-03 912.874848  下跌 4.57% (当日跌)
2020-01-06 912.392410  微跌 0.05%
```

### 2.6 `volume` — 成交量

- **含义**: 当日所有成交的股票数量
- **单位**: 股（注意不是手，1手=100股）
- **类型**: 整数（int64）
- **用途**: 衡量当日交易活跃度

**示例**:
```
date       volume     解读
2020-01-02 14809916    约1481万股，正常交易量
2020-01-03 13031878    约1303万股，较前日缩量
2020-01-06  6341478    约634万股，大幅缩量（可能因假期临近）
```

### 2.7 `amount` — 成交额

- **含义**: 当日所有成交的总金额
- **单位**: 人民币元
- **计算关系**: amount ≈ Σ(每笔成交价 × 每笔成交量)
- **注意**:
  - 成交额通常为正数
  - 数量级较大，可能以科学计数法表示（如 `1.669684e+10` = 166.97亿元）
  - 与成交量关系: 平均成交价 ≈ amount / volume

**示例**:
```
date       volume      amount            平均成交价
2020-01-02 14809916    1.669684e+10      16696837095/14809916 ≈ 1127.3元
```
> 注: 实际平均成交价略高于收盘价，因为成交额包含全天所有价位成交

### 2.8 `code` — 股票代码

- **含义**: 股票的6位数字代码
- **类型**: 整数
- **格式**:
  - `6xxxxx` — 上海证券交易所主板（沪A）
  - `00xxxx` — 深圳证券交易所主板（深A）
  - `30xxxx` — 深圳证券交易所创业板
  - `688xxx` — 上海证券交易所科创板

**示例**:
```
code    市场
000001  深市主板
600519  沪市主板
300750  创业板
688981  科创板
```

### 2.9 `name` — 股票名称

- **含义**: 股票的中文简称
- **类型**: 字符串
- **注意**: 股票名称可能变更（如退市摘牌、名称变更），本数据使用当前名称

**示例**:
```
code     name
600519   贵州茅台
000001   平潭发展
300750   宁德时代
688981   中芯国际
```

## 四、前复权说明

### 什么是前复权？

前复权是指以当前价格为基准，对历史价格进行向下调整，使得分红送股后的K线图连续。

### 为什么需要前复权？

假设某股票10送10（每10股送10股），除权日收盘价从100元变为50元。如果不复权：
- K线图上会出现一个巨大的向下跳空缺口
- 技术指标（MA、MACD等）会严重失真

前复权后，除权日前所有历史价格都除以2，K线连续，技术分析准确。

### 前复权的缺陷

1. **历史价格可能为负**: 极端情况下，多次分红后复权价格可能变为负数
2. **不同数据源算法不同**: 前复权计算方式各数据源略有差异，跨源对比需注意
3. **不适合绝对价格分析**: 前复权价格不是实际交易价格，不能用于计算绝对盈亏
4. **适合收益率计算**: 前复权数据非常适合计算累计收益率、波动率等

### 示例

假设某股票:
- 2020-01-02: 实际收盘价 100元，前复权价 100元
- 2020-06-01: 10送10，除权日实际收盘 50元，前复权价 50元（调整后历史价格也×0.5）
- 2020-06-02: 实际收盘价 55元，前复权价 55元

如果不复权，6月1日会出现50%的跳空下跌。前复权后，1月2日的前复权价变为50元，K线连续。

## 五、常见数据处理场景

### 5.1 计算日收益率

```python
import pandas as pd

df = pd.read_csv('600519_贵州茅台.csv')
df['return'] = df['close'].pct_change() * 100  # 日收益率(%)
print(df[['date', 'close', 'return']].head(10))
```

### 5.2 计算周/月收益率

```python
df['week_return'] = df['close'].resample('W', on='date')['close'].apply(lambda x: (x.iloc[-1]/x.iloc[0]-1)*100)
df['month_return'] = df['close'].resample('M', on='date')['close'].apply(lambda x: (x.iloc[-1]/x.iloc[0]-1)*100)
```

### 5.3 处理停牌日

```python
# 前向填充收盘价，模拟停牌日价格不变
df['close_filled'] = df['close'].fillna(method='ffill')

# 或者标记停牌日
df['is_trade_day'] = df['date'].diff().dt.days <= 3  # 间隔≤3天认为是交易日
```

### 5.4 计算MA均线

```python
df['MA5'] = df['close'].rolling(5).mean()
df['MA20'] = df['close'].rolling(20).mean()
df['MA60'] = df['close'].rolling(60).mean()
```

### 5.5 计算涨跌幅

```python
df['pct_change'] = df['close'].pct_change() * 100
# 限制涨跌幅为±20%（科创板/创业板±20%，主板±10%）
df['pct_change'] = df['pct_change'].clip(-20, 20)
```

## 六、数据质量与已知问题

### 6.1 数据覆盖

| 情况 | 说明 |
|------|------|
| 正常上市股票 | 从2020-01-02起有完整数据 |
| 2020年后上市 | 数据从上市日起有记录 |
| 2020年前退市 | 数据到退市日止 |
| 科创板(688) | 部分股票2020-07前无数据（科创板2020年7月开板） |
| ST/*ST股票 | 数据完整，但交易特征与普通股票不同 |

### 6.2 数据精度

| 字段 | 精度 | 说明 |
|------|------|------|
| open/high/low/close | 约6位小数 | 浮点数精度限制 |
| volume | 整数 | 精确到股 |
| amount | 约1位小数 | 浮点数精度限制 |

### 6.3 已知缺陷

1. **日期缺失**: 停牌期间无记录，需手动填充或前向填充
2. **复权滞后**: Baostock数据通常T+1更新，最新交易日数据可能不完整
3. **成分股变化**: 沪深300每半年调整一次，本数据使用当前成分股回溯，历史回测需注意
4. **名称变更**: 部分股票名称已变更，`name`字段使用当前名称
5. **极端值**: 极少数股票可能存在异常价格（如新股上市首日），需自行过滤

### 6.4 使用建议

1. **回测时**: 建议使用滚动成分股（根据历史日期确定当日成分股），而非固定使用当前成分股
2. **计算收益**: 使用前复权数据，不适合计算绝对价格
3. **停牌处理**: 使用前向填充收盘价模拟停牌日价格
4. **异常过滤**: 建议过滤掉涨跌幅超过±20%的异常日（新股上市首日等）

## 七、快速参考

```python
import pandas as pd
import os

# 读取单只股票
df = pd.read_csv('600519_贵州茅台.csv')

# 读取所有股票并合并
folder = './csi300_daily_data'
all_data = []
for f in os.listdir(folder):
    if f.endswith('.csv'):
        df = pd.read_csv(os.path.join(folder, f))
        all_data.append(df)
combined = pd.concat(all_data, ignore_index=True)

# 基本统计
print(f"总记录: {len(combined):,}")
print(f"日期范围: {combined['date'].min()} ~ {combined['date'].max()}")
print(f"股票数量: {combined['code'].nunique()}")

# 按日汇总（当日所有股票成交额）
daily_summary = combined.groupby('date').agg({
    'volume': 'sum',
    'amount': 'sum'
}).reset_index()
```
